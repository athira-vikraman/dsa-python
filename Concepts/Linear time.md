# Linear time

**O(n)** — you touch each item a constant number of times.

One loop over the input. Double the input, double the time. `sum()`, `max()`,
`x in my_list`, a single pass over a file.

> Two passes is still O(n). `n + n = 2n`, and constants get dropped. **Only
> nested loops multiply.** Beginners lose marks on this constantly.
