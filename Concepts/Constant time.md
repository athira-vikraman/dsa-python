# Constant time

**O(1)** — the work does not depend on the input size at all. A list of 10 or
10 billion: the same number of steps.

Index a box, look up a dictionary key, push onto the end of a list, do some
arithmetic. Flipping a light switch — the size of the room is irrelevant.

> The same symbol is used for **O(1) space**: a fixed number of variables, no
> matter how big the input. That is what "in place" means. See
> [[Concepts/In-place algorithms|In-place algorithms]].
